OTTSubは、アカウント登録や有料サブスクリプション不要で無料で使える、Netflix向けの字幕タイミング調整＆二言語同時表示Chrome拡張機能です。動画の横に表示されるChromeサイドパネルやキーボードショートカットから、字幕の同期ズレ補正、外観スタイル、ぼかし学習機能を簡単に操作できます。
Netflix（ネットフリックス）の字幕がセリフより早すぎたり遅すぎたりしませんか？語学学習のために2つの言語の字幕（二言語字幕）を同時に表示して視聴したいですか？

使い方：デスクトップ版ChromeにOTTSubをインストールし、Netflixのウェブサイトで動画を開いて、OTTSubアイコンからサイドパネルを開きます。利用可能な主字幕と副字幕を選び、それぞれのタイミングを調整します。Netflixアプリ内で動作する機能ではありません。

主な機能

1. 言語ごとの独立したタイミング調整（字幕シンク）
• 主字幕と副字幕のタイミングをそれぞれ独立して進めたり遅らせたりできます。
• サイドパネルのスライダー、マウスホイール、またはキーボードショートカットで0.1秒（100ms）単位の微調整が可能です。
• 各言語のタイミング補正値をいつでも個別に0.0秒へリセットできます。

2. 二言語字幕の同時表示＆CC/SDHの選択
• 視聴中の作品で利用可能な字幕トラックから、主字幕と副字幕を選んで画面に同時表示します。
• 主字幕は手動選択または自動選択（英語を優先し、ない場合は最初に利用可能な字幕トラックを選択）に対応しています。
• 作品側で提供されている場合、通常の字幕またはCC/SDH（音声ガイド・効果音や話者情報を含むバリアフリー字幕）を選択できます。
• 利用できる言語や字幕トラックはNetflixの作品およびアカウントによって異なります。OTTSubが機械翻訳を自動生成したり、Netflixが提供していない字幕を追加したりすることはありません。

3. 字幕のサイズ・色・背景・位置のカスタマイズ
• 言語別の文字サイズ調整：主字幕は60〜140%、副字幕は60〜120%。
• 言語別の4色の文字カラー：ホワイト、イエロー、ミント、グリーン。
• 言語ごとの半透明の黒背景ボックスのオン／オフ。
• 行間（0〜6段階）および垂直位置（−50〜+50ピクセル）の調整。
• マウスドラッグで字幕を自由に移動でき、位置ロック機能で再生バー操作時の干渉を防げます。

4. 語学学習ツール（字幕ぼかし＆ホバー一時停止）
• 主字幕、副字幕、または両方の字幕にぼかし（弱 4px / 中 8px / 強 14px）をかけて隠し、マウスカーソルを重ねたときだけテキストを表示できます。
• 字幕にマウスカーソルを重ねると動画を自動的に一時停止するオプションを利用できます。

5. 広告検出と再生位置移動（シーク）への対応
• 検出された広告の再生中は、OTTSubの字幕を自動的に非表示にします。
• 広告終了後や早送り・巻き戻し（シーク）後は、再生時間を確認してからOTTSubの字幕を再表示します。
• 確認の間は、Netflixプレイヤー側で選択されている言語の元の字幕が一時的に表示される場合があります。

キーボードショートカット
[ / ] : 主字幕のタイミングを −0.1秒 / +0.1秒 調整
\ : 主字幕のタイミングを 0.0秒 にリセット
Alt + [ / Alt + ] : 副字幕のタイミングを −0.1秒 / +0.1秒 調整
Alt + \ : 副字幕のタイミングを 0.0秒 にリセット
Alt + D : 二言語字幕のオン／オフ切り替え
Alt + L : 字幕位置ロックのオン／オフ切り替え
Alt + B : 学習用ぼかし／非表示のオン／オフ切り替え
Alt + R : 字幕位置を初期位置にリセット（または字幕をダブルクリック）
• Mac（macOS）ではAltの代わりにOptionキーを使用します。サイドパネルにはお使いのOSに合ったショートカットが自動表示されます。
• 表示されているキーはUSキーボードの物理配置を基準としています（配列によって印字記号が異なる場合があります）。

インターフェース対応言語（16言語）
アラビア語、ベンガル語、中国語 (繁体字、台湾)、英語、フィンランド語、ドイツ語、ヘブライ語、ヒンディー語、日本語、韓国語、マレー語、ポルトガル語 (イベリア半島)、ロシア語、スペイン語、タイ語、トルコ語。（メニューの表示言語は、Netflixの作品で提供される字幕トラックの言語とは独立しています。）

よくある質問（FAQ）
Q. 主字幕と副字幕のタイミング（ズレ）を別々に調整できますか？
A. はい、主字幕と副字幕のタイミングをそれぞれ0.1秒単位で独立して調整できます。

Q. 無料で使えますか？会員登録は必要ですか？
A. 完全無料で利用でき、アカウント登録やログイン、課金は一切不要です。 Netflixのアカウントと契約は別途必要で、OTTSubには含まれません。

Q. 字幕を自動翻訳する機能はありますか？
A. いいえ。OTTSubは機械翻訳ツールではなく、視聴中のNetflix作品で公式に提供されている字幕トラックを読み込んで同時表示・タイミング調整を行います。

Q. MacやMicrosoft Edgeなどのブラウザでも動作しますか？
A. デスクトップ版Chromeを対象とし、Windows版Microsoft Edgeもローカル互換性テストに合格しています。macOSではOptionキーのショートカットを提供しますが、Macでの検証は一部のみ完了しています。他のChromium系ブラウザの互換性は未検証です。このパッケージはモバイル版ChromeやSafariには対応していません。

Q. 希望する字幕言語が一覧にない場合は？
A. OTTSubは、現在のNetflix作品とアカウントで利用できる字幕トラックを使います。OTTSubのメニュー言語を変更しても字幕トラックの追加や翻訳は行われません。まずNetflixがその作品で提供している字幕言語をご確認ください。

プライバシーと動作の仕組み
Chromeウェブストア版には、ローカル診断レコーダー、利用分析ツール、視聴履歴の追跡機能は含まれていません。Netflixのサービスから取得した字幕トラックはお使いのブラウザ内で処理され、設定はChromeのストレージに保存されます。

Netflixの視聴権限が必要です。OTTSubは独立した拡張機能であり、Netflixと提携または承認された製品ではありません。
