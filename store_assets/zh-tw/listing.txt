OTTSub 是一款免費的 Chrome 擴充功能，無需註冊帳號、無需訂閱且無廣告，即可微調 Netflix 字幕時間偏移並同時顯示兩種字幕軌。透過影片旁的 Chrome 側邊面板或鍵盤快速鍵，輕鬆調整字幕時間、外觀樣式與模糊遮蔽學習工具。
Netflix 字幕總是比對白快或慢嗎？想在觀看 Netflix 時同時顯示雙語字幕來學習外語嗎？

開始使用：在電腦版 Chrome 安裝 OTTSub，於 Netflix 網站開啟影片，再按 OTTSub 圖示開啟側邊面板。選取可用的主要與輔助字幕軌，分別調整時間。OTTSub 不會在 Netflix App 內執行。

主要功能

1. 各語言獨立調整時間（字幕同步偏移）
• 分別將主要字幕與輔助字幕提前或延後。
• 使用側邊面板滑桿、滑鼠滾輪或鍵盤快速鍵，以 0.1 秒（100 毫秒）為單位微調時間。
• 隨時將各語言的時間偏移獨立重設為 0.0 秒。

2. 雙語字幕同時顯示與 CC/SDH 選擇
• 從目前觀看作品所提供的字幕軌中，選擇主要語言與輔助語言同時顯示於畫面上。
• 主要字幕可手動選擇或使用自動選擇（優先選擇英文，若無則選擇第一個可用的字幕軌）。
• 當作品有提供時，可選擇一般字幕或 CC/SDH（包含聲音描述與說話者標示的隱藏式字幕）。
• 可用的語言與字幕軌取決於 Netflix 作品及您的帳戶。OTTSub 不會自動產生機器翻譯，也不會新增 Netflix 未提供的字幕軌。

3. 字幕外觀、滑鼠拖曳與位置鎖定
• 各語言獨立調整字體大小：主要字幕 60–140%，輔助字幕 60–120%。
• 四種文字顏色：純白、暖黃、薄荷色與柔和綠。
• 各語言可分別開啟或關閉半透明黑色背景方框。
• 調整行距（0–6 級）與垂直位置（−50 至 +50 像素）。
• 使用滑鼠自由拖曳字幕位置，並可鎖定位置以避免干擾播放進度列操作。

4. 語言學習工具（字幕模糊遮蔽與懸停暫停）
• 將主要字幕、輔助字幕或兩者設為模糊（輕度 4px / 中度 8px / 重度 14px）或隱藏，滑鼠游標移到字幕上時才顯示文字。
• 可開啟「滑鼠移到字幕上時自動暫停影片」功能，方便逐句學習。

5. 廣告偵測與播放位置跳轉驗證
• 在偵測到廣告播放期間，OTTSub 會自動隱藏其字幕。
• 廣告結束後或快轉／倒轉跳轉後，會先確認播放時間再恢復顯示 OTTSub 字幕。
• 在確認時間期間，畫面可能會暫時顯示 Netflix 原生選擇語言的原始字幕。

鍵盤快速鍵
[ / ] : 將主要字幕時間調整 −0.1 / +0.1 秒
\ : 將主要字幕時間重設為 0.0 秒
Alt + [ / Alt + ] : 將輔助字幕時間調整 −0.1 / +0.1 秒
Alt + \ : 將輔助字幕時間重設為 0.0 秒
Alt + D : 開啟或關閉雙語字幕
Alt + L : 鎖定或解鎖字幕位置
Alt + B : 開啟或關閉字幕模糊／隱藏學習效果
Alt + R : 將字幕位置重設為預設值（或連按兩下字幕）
• 在 Mac（macOS）上請使用 Option 代替 Alt。側邊面板會自動顯示符合您作業系統的快速鍵。
• 顯示的按鍵位置以美式（US）鍵盤實體配置為準；其他鍵盤配置上的印刷符號可能不同。

常見問題（FAQ）
Q. 可以分別調整主要字幕和輔助字幕的時間同步嗎？
A. 可以，主要字幕與輔助字幕皆能以 0.1 秒為單位各自獨立提前或延後。

Q. OTTSub 是免費的嗎？需要註冊帳號嗎？
A. 完全免費，無需註冊、登入或付費訂閱。 仍須另備 Netflix 帳號與訂閱，OTTSub 並不包含這些服務。

Q. OTTSub 會自動翻譯字幕嗎？
A. 不會。OTTSub 並非機器翻譯工具，而是載入並同步 Netflix 為該作品官方提供的字幕軌。

Q. 支援 Mac 以及 Microsoft Edge 等瀏覽器嗎？
A. OTTSub 以電腦版 Chrome 為對象，Windows 版 Microsoft Edge 也已通過本機相容性測試。macOS 提供 Option 快速鍵，但 Mac 僅完成部分驗證；其他 Chromium 瀏覽器的相容性尚未驗證。此套件不支援行動版 Chrome 或 Safari。

Q. 找不到想要的字幕語言怎麼辦？
A. OTTSub 使用目前 Netflix 作品與帳號可用的字幕軌。更改 OTTSub 選單語言不會新增或翻譯字幕軌，請先確認 Netflix 為該作品提供哪些字幕語言。

隱私權與運作方式
Chrome 線上應用程式商店版本不包含本機診斷記錄器、分析工具或觀看紀錄追蹤功能。從 Netflix 服務接收的字幕軌僅在您的瀏覽器內處理，偏好設定則儲存於 Chrome 儲存空間中。

需具備 Netflix 使用權限。OTTSub 為獨立開發的擴充功能，與 Netflix 無關，亦未獲 Netflix 背書或贊助。
