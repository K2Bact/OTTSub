OTTSub คือส่วนขยายฟรีสำหรับ Chrome บนคอมพิวเตอร์ ช่วยปรับเวลาคำบรรยาย Netflix และแสดงคำบรรยายสองภาษาพร้อมกัน ใช้การตั้งค่าในแผงด้านข้างหรือปุ่มลัดเพื่อปรับเวลา รูปแบบข้อความ และเครื่องมือฝึกภาษา OTTSub ไม่มีโฆษณาและไม่ต้องสมัครบัญชีเพิ่ม แต่การรับชม Netflix ต้องมีบัญชีและสิทธิ์รับชมของ Netflix แยกต่างหาก

เริ่มใช้งาน
ติดตั้ง OTTSub ใน Chrome บนคอมพิวเตอร์ เปิดวิดีโอบนเว็บไซต์ Netflix แล้วคลิกไอคอน OTTSub เพื่อเปิดแผงด้านข้าง เลือกภาษาหลักและภาษารองจากคำบรรยายที่มี แล้วปรับเวลาแต่ละภาษาแยกกัน ส่วนขยายนี้ไม่ทำงานภายในแอป Netflix

ความสามารถหลัก

• ปรับเวลาคำบรรยายหลักและรองแยกกัน เพิ่มหรือลดครั้งละ 0.1 วินาทีด้วยแถบเลื่อน ล้อเมาส์ หรือปุ่มลัด และตั้งเวลาใหม่เป็น 0.0s ได้
• แสดงคำบรรยายสองภาษาพร้อมกัน โดยใช้แทร็กที่มีสำหรับวิดีโอและบัญชี Netflix ของคุณ ไม่สร้างคำแปลใหม่หรือเพิ่มแทร็กที่ Netflix ไม่มี
• เลือกคำบรรยายปกติหรือ CC/SDH เมื่อมีให้เลือก CC/SDH อาจมีข้อมูลผู้พูด ดนตรี และเสียงประกอบเพิ่มเติม
• ปรับขนาด สี พื้นหลัง ระยะห่างบรรทัด และตำแหน่งของแต่ละภาษา ลากคำบรรยายเมื่อปลดล็อก หรือล็อกตำแหน่งตามต้องการ
• เบลอหรือซ่อนคำบรรยายหลัก คำบรรยายรอง หรือทั้งคู่เพื่อฝึกความเข้าใจ และหยุดวิดีโอชั่วคราวเมื่อชี้เมาส์บนคำบรรยาย
• รองรับเมนู 16 ภาษา รวมภาษาไทยและภาษาฟินแลนด์ การเลือกภาษาเมนูไม่เปลี่ยนภาษาหรือแทร็กคำบรรยายที่ Netflix มีให้

ปุ่มลัด

[ / ]: ปรับเวลาคำบรรยายหลักครั้งละ 0.1 วินาที
Alt + [ / ]: ปรับเวลาคำบรรยายรองครั้งละ 0.1 วินาที
\: ตั้งเวลาคำบรรยายหลักใหม่เป็น 0.0s
Alt + \: ตั้งเวลาคำบรรยายรองใหม่เป็น 0.0s
Alt + D: เปิดหรือปิดคำบรรยายคู่
Alt + B: เปิดหรือปิดการเบลอหรือซ่อนคำบรรยาย
Alt + L: ล็อกหรือปลดล็อกตำแหน่งคำบรรยาย
Alt + R: คืนตำแหน่งคำบรรยายเริ่มต้น

บน Mac ใช้ Option แทน Alt ตำแหน่งปุ่มอ้างอิงแป้นพิมพ์แบบสหรัฐฯ สัญลักษณ์ที่พิมพ์บนปุ่มอาจต่างกันตามรูปแบบแป้นพิมพ์ ใช้ตัวควบคุมบนหน้าจอได้เช่นกัน

คำถามที่พบบ่อย

ต้องจ่ายเงินหรือสมัครบัญชี OTTSub หรือไม่?
ไม่ต้อง OTTSub ใช้ฟรี ไม่มีโฆษณา และไม่ต้องสมัครบัญชี OTTSub ส่วนบัญชีและสิทธิ์รับชม Netflix เป็นเงื่อนไขแยกต่างหาก

OTTSub แปลคำบรรยายให้หรือไม่?
ไม่แปล OTTSub ใช้แทร็กคำบรรยายที่ Netflix มีสำหรับวิดีโอและบัญชีปัจจุบัน จึงไม่รับประกันว่าจะมีทุกภาษาหรือทุกเรื่อง

ทำไมต้องปรับเวลาคำบรรยาย?
หากคำบรรยายเร็วหรือช้ากว่าเสียง ให้เพิ่มหรือลดค่าเลื่อนเวลาในแผงด้านข้าง ปรับคำบรรยายหลักและรองแยกกันได้ตามต้องการ

ใช้บนมือถือ Safari หรือแอป Netflix ได้หรือไม่?
ชุดนี้ออกแบบสำหรับ Chrome บนคอมพิวเตอร์และเว็บไซต์ Netflix ไม่รองรับ Chrome บนมือถือ Safari หรือการทำงานภายในแอป Netflix การตรวจสอบบน Mac ยังเสร็จเพียงบางส่วน และไม่ได้รับประกันความเข้ากันได้กับเบราว์เซอร์ Chromium ทุกตัว

ถ้าไม่มีภาษาคำบรรยายที่ต้องการควรทำอย่างไร?
ตรวจสอบเมนูคำบรรยาย Netflix ของวิดีโอนั้นก่อน หาก OTTSub แจ้งว่ากำลังรอ URL ให้เลือกภาษานั้นหนึ่งครั้งในเมนู Netflix เพื่อขอโหลด การเปลี่ยนภาษาเมนู OTTSub จะไม่เพิ่มภาษาคำบรรยายให้ Netflix
