OTTSub הוא תוסף חינמי ל־Chrome המאפשר לכוון את תזמון הכתוביות ב־Netflix ולהציג יחד שני ערוצי כתוביות הזמינים בכותר שבו צופים — ללא הרשמה, ללא מנוי וללא פרסומות. אפשר לבחור שפות, להתאים את המראה ולהשתמש בכלי הלמידה דרך החלונית הצדדית של Chrome לצד הסרטון או באמצעות קיצורי מקשים.
הכתוביות ב־Netflix מקדימות את הדיבור או מופיעות באיחור? רוצים לצפות ב־Netflix עם כתוביות בשתי שפות במקביל כדי לתרגל שפה נוספת?

תחילת העבודה: מתקינים את OTTSub ב־Chrome במחשב, פותחים סרטון באתר Netflix ולוחצים על סמל OTTSub כדי לפתוח את החלונית הצדדית. בוחרים ערוצי כתוביות ראשיים ומשניים זמינים ומכוונים את התזמון בנפרד. OTTSub אינו פועל בתוך אפליקציית Netflix.

תכונות עיקריות

1. תזמון נפרד לכל שפה (סנכרון עצמאי)
• מקדימים או מאחרים את הכתוביות בשפה הראשית ובשפה המשנית בנפרד.
• מכוונים בצעדים של 0.1 שניות באמצעות המחוון בחלונית, גלגלת העכבר או קיצורי מקשים.
• אפשר לאפס את התזמון של כל שפה ל־0.0 שניות בנפרד.

2. כתוביות בשתי שפות במקביל ובחירת CC/SDH
• בוחרים שפה ראשית ושפה משנית מתוך ערוצי הכתוביות הזמינים בכותר.
• אפשר להשתמש בבחירה אוטומטית של השפה הראשית (המעדיפה קודם אנגלית ולאחר מכן את הערוץ הזמין הראשון) או לבחור אותה ידנית.
• כשזמינות אפשרויות מתאימות, אפשר לבחור כתוביות רגילות או CC/SDH (העשויות לכלול גם תיאורי צלילים ומידע על הדוברים).
• זמינות השפות והערוצים תלויה בכותר ובחשבון Netflix. OTTSub אינו יוצר תרגום מכונה אוטומטי.

3. מראה, גרירה בעכבר ונעילת מיקום
• משנים את גודל הכתוביות לכל שפה בנפרד: 60–140% לשפה הראשית ו־60–120% לשפה המשנית.
• בוחרים צבע לבן, צהוב, מנטה או ירוק לכל שפה.
• מפעילים או מכבים רקע שחור שקוף למחצה לכל שפה.
• מכוונים את המרווח בין השורות ב־0–6 דרגות ואת המיקום האנכי בין ‎−50 ל־‎+50 פיקסלים.
• גוררים את הכתוביות בעכבר ונועלים את מיקומן כדי למנוע הפרעה לסרגל הניגון.

4. כלים ללימוד שפה (טשטוש והשהיה בריחוף)
• מטשטשים (4px / 8px / 14px) או מסתירים שפה אחת או את שתיהן, וחושפים את הטקסט בריחוף עם העכבר.
• אפשר להפעיל השהיית סרטון אוטומטית בעת ריחוף על הכתוביות.

5. פרסומות ושינויים במיקום ההפעלה
• OTTSub מסתיר את הכתוביות שלו בזמן פרסומות שזוהו.
• אחרי פרסומת או דילוג בסרטון, התוסף בודק את זמן ההפעלה לפני חידוש התצוגה.
• בזמן הבדיקה עשויות להופיע זמנית הכתוביות המקוריות בשפה שנבחרה ב־Netflix.

קיצורי מקשים
‎[ / ] : כיוון תזמון השפה הראשית ב־‎−0.1 / +0.1 שניות
‎\ : איפוס תזמון השפה הראשית ל־0.0 שניות
‎Alt + [ / Alt + ] : כיוון תזמון השפה המשנית ב־‎−0.1 / +0.1 שניות
‎Alt + \ : איפוס תזמון השפה המשנית ל־0.0 שניות
‎Alt + D : הפעלה או כיבוי של כתוביות בשתי שפות
‎Alt + L : נעילה או שחרור של מיקום הכתוביות
‎Alt + B : הפעלה או כיבוי של אפקט הטשטוש או ההסתרה ללימוד
‎Alt + R : איפוס מיקום הכתוביות לברירת המחדל (או לחיצה כפולה)
• ב־Mac (macOS) משתמשים ב־Option במקום Alt. בחלונית מוצגים אוטומטית הקיצורים המתאימים למערכת.
• מיקומי המקשים מתייחסים למקלדת אמריקאית (US); הסימנים המודפסים עשויים להשתנות בפריסות אחרות. ניתן להשתמש גם במחוון בחלונית.

שאלות נפוצות (FAQ)
ש. האם אפשר לכוון את סנכרון הכתוביות לכל שפה בנפרד?
ת. כן, ניתן להקדים או לאחר את הכתוביות הראשיות והמשניות בנפרד בצעדים של 0.1 שניות.

ש. האם התוסף חינמי? האם צריך להירשם?
ת. OTTSub חינמי לחלוטין ופועל ללא צורך בהרשמה או במנוי. חשבון ומנוי Netflix נדרשים בנפרד ואינם כלולים ב־OTTSub.

ש. האם OTTSub מתרגם כתוביות באופן אוטומטי?
ת. לא. התוסף אינו מבצע תרגום מכונה, אלא טוען ומסנכרן את ערוצי הכתוביות הרשמיים ש־Netflix מספקת עבור הכותר.

ש. האם התוסף פועל ב־Mac ובדפדפנים כמו Microsoft Edge?
ת. OTTSub מיועד ל־Chrome במחשב; גם Microsoft Edge ב־Windows עבר בדיקות תאימות מקומיות. ב־macOS יש קיצורי Option, אך האימות ב־Mac הושלם רק בחלקו. התאימות לדפדפני Chromium אחרים לא אומתה. חבילה זו אינה תומכת ב־Chrome בנייד או ב־Safari.

ש. מה עושים אם שפת הכתוביות הרצויה אינה מופיעה?
ת. OTTSub משתמש בערוצים הזמינים לכותר ולחשבון Netflix הנוכחיים. שינוי שפת התפריט של OTTSub אינו מוסיף ערוצים ואינו מתרגם אותם. תחילה בדקו אילו שפות כתוביות Netflix מציעה לכותר הזה.

פרטיות ואופן הפעולה
גרסת Chrome Web Store אינה כוללת כלי הקלטה לאבחון מקומי, כלי ניתוח שימוש או מעקב אחר היסטוריית הצפייה. התוסף מקבל ערוצי כתוביות משירותי Netflix ומעבד אותם בדפדפן. ההעדפות נשמרות באחסון של Chrome.
