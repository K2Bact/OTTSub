OTTSub는 Netflix 자막의 싱크를 미세 조절하고 두 언어 자막을 동시에 표시하는 무료 Chrome 확장 프로그램입니다. OTTSub 전용 회원가입이나 유료 구독은 필요하지 않습니다. Netflix 계정과 구독은 별도로 필요합니다. 브라우저 사이드패널과 단축키로 자막 타이밍, 모양, 학습용 블러 효과를 조절할 수 있습니다.
넷플릭스(Netflix) 자막 싱크가 대사보다 빠르거나 느린가요? 영어·한국어 등 두 언어 자막(이중 자막)을 동시에 띄워 놓고 외국어를 학습하고 싶으신가요?

시작하기: 데스크톱용 Chrome 114 이상에서 OTTSub를 설치하고 Netflix 웹사이트의 영상을 연 다음, OTTSub 아이콘을 눌러 사이드패널을 여세요. 작품에서 제공되는 주언어·보조언어 자막을 선택하고 각 언어의 싱크를 조절하세요. Netflix 앱 안에서 실행되는 기능은 아닙니다.

주요 기능

1. 언어별 독립 자막 싱크(타이밍) 조절
• 주언어 자막과 보조언어 자막의 싱크를 각각 독립적으로 앞당기거나 늦출 수 있습니다.
• 사이드패널 슬라이더, 마우스 휠 또는 키보드 단축키로 0.1초(100ms) 단위 미세 조절을 지원합니다.
• 각 언어의 싱크 오프셋을 언제든 개별적으로 0.0초로 초기화할 수 있습니다.

2. 두 언어 자막 동시 표시 (이중 자막 & CC/SDH 선택)
• 시청 중인 작품에서 제공하는 자막 트랙 중 주언어와 보조언어를 선택해 화면에 동시에 표시합니다.
• 주언어는 직접 선택하거나 자동 선택(영어를 우선 선택하고, 없을 경우 첫 번째 사용 가능한 자막 트랙 선택)을 사용할 수 있습니다.
• 작품에서 제공할 경우 일반 대사 자막과 CC/SDH(청각장애인용 소리 설명·화자 표시 포함) 트랙을 구분해 선택할 수 있습니다.
• 사용 가능한 자막 언어와 트랙 종류는 넷플릭스 작품 및 계정에 따라 다르며, OTTSub가 자체적으로 기계 번역을 생성하거나 없는 트랙을 추가하지는 않습니다.

3. 자막 크기·색상·배경·위치 맞춤 설정
• 언어별 독립 글자 크기 조절: 주언어 60~140%, 보조언어 60~120%.
• 언어별 4가지 글자 색상 선택: 화이트, 옐로우, 민트, 그린.
• 언어별 반투명 검정 배경 박스 켜기/끄기.
• 줄 간격(0~6단계) 및 수직 위치(−50~+50px) 미세 조정.
• 마우스 드래그로 자막 위치를 자유롭게 이동하고, 위치 잠금으로 재생바 조작 시 간섭을 방지할 수 있습니다.

4. 외국어 학습 도구 (자막 블러/가림 & 자동 일시정지)
• 주언어, 보조언어 또는 양쪽 자막 모두에 블러(약함 4px / 보통 8px / 강함 14px) 효과를 적용해 가려두고, 마우스를 올렸을 때만 대사를 확인할 수 있습니다.
• 자막 위에 마우스를 올리면 영상이 자동으로 일시정지되고, 마우스를 치우면 다시 재생되는 학습 옵션을 지원합니다.

5. 광고 감지 및 재생 위치 이동(탐색) 대응
• 감지된 광고 재생 중에는 OTTSub 자막을 자동으로 숨깁니다.
• OTTSub는 Netflix 광고를 차단하거나 제거하지 않습니다.
• 광고 종료 후 또는 영상 앞뒤 탐색(Seek) 후에는 실제 재생 시간을 확인한 뒤 OTTSub 자막을 다시 표시합니다.
• 시간 확인이 진행되는 동안에는 넷플릭스 플레이어에서 선택한 언어의 원본 자막이 일시적으로 표시될 수 있습니다.

키보드 단축키 안내
[ / ] : 주언어 자막 싱크 −0.1초 / +0.1초 조절
\ : 주언어 자막 싱크 0.0초 초기화
Alt + [ / Alt + ] : 보조언어 자막 싱크 −0.1초 / +0.1초 조절
Alt + \ : 보조언어 자막 싱크 0.0초 초기화
Alt + D : 이중 자막 켜기/끄기
Alt + L : 자막 위치 잠금 켜기/끄기
Alt + B : 학습용 자막 가림(블러) 켜기/끄기
Alt + R : 자막 위치 기본값 초기화 (또는 자막 더블클릭)
• Mac(macOS)에서는 Alt 대신 Option 키를 사용하며, 운영체제에 맞는 단축키가 사이드패널에 자동 표시됩니다.

지원 인터페이스 언어 (16개 언어)
아랍어, 벵골어, 중국어(번체, 대만), 영어, 핀란드어, 독일어, 히브리어, 힌디어, 일본어, 한국어, 말레이어, 포르투갈어(유럽), 러시아어, 스페인어, 태국어, 튀르키예어. (확장 프로그램 메뉴 언어는 넷플릭스 영상에서 제공되는 자막 트랙 언어와 별개입니다.)

자주 묻는 질문 (FAQ)
Q. 주언어와 보조언어 자막 싱크가 서로 다를 때 따로 맞출 수 있나요?
A. 네, 주언어([, ])와 보조언어(Alt + [, Alt + ] 또는 Mac Option + [, Option + ])의 타이밍을 0.1초 단위로 각각 독립 조절할 수 있습니다.

Q. 회원가입이나 유료 결제가 필요한가요?
A. 아니요, 별도 계정 가입이나 로그인 없이 무료로 모든 기능을 사용할 수 있습니다. Netflix 계정과 구독은 별도로 필요하며 OTTSub에 포함되지 않습니다.

Q. 자동 번역 기능도 제공하나요?
A. 아니요, OTTSub는 기계 번역기가 아니며 시청 중인 넷플릭스 작품에서 공식 제공하는 자막 트랙들을 불러와 동시에 표시하고 싱크를 조절합니다.

Q. Mac이나 Edge 브라우저에서도 작동하나요?
A. 데스크톱 Chrome을 대상으로 하며 Windows의 Microsoft Edge도 로컬 호환성 검사를 통과했습니다. macOS용 Option 단축키를 제공하지만 Mac 검증은 일부만 완료했습니다. 다른 Chromium 브라우저의 호환성은 확인하지 않았습니다. 이 패키지는 모바일 Chrome이나 Safari를 지원하지 않습니다.

Q. 원하는 자막 언어가 목록에 없으면 어떻게 하나요?
A. OTTSub는 현재 Netflix 작품·계정에서 제공하는 자막 트랙을 사용합니다. OTTSub 메뉴 언어를 바꿔도 자막 트랙이 추가되거나 번역되지 않습니다. 먼저 Netflix에서 해당 작품에 제공되는 자막 언어를 확인하세요.

개인정보 보호 및 동작 방식
Chrome 웹 스토어 배포판에는 로컬 진단 기록 도구, 사용 통계 분석 도구, 시청 기록 추적 기능이 포함되지 않습니다. 넷플릭스 서비스에서 받은 자막 트랙은 사용자의 브라우저 안에서만 처리되며, 사용자 환경설정은 Chrome 저장소(chrome.storage)에 보관됩니다.

넷플릭스(Netflix) 이용 권한이 필요합니다. OTTSub는 독립적으로 개발된 확장 프로그램이며 Netflix와 제휴하거나 승인받은 제품이 아닙니다.
