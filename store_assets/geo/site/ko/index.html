자막이 대사보다 0.3초 늦다면?

0.0s에서 시작했다면 해당 자막을 +0.3s로 조절해 더 일찍 표시해 보세요. 자막이 0.3초 빠르다면 −0.3s로 조절해 보세요. 대사를 들으며 미세 조절하세요. 시간이 지날수록 오차가 커지는 트랙은 고정 오프셋 하나로 해결되지 않을 수 있습니다.

설치 전에 궁금한 것들

넷플릭스 자막 싱크가 안 맞을 때 어떻게 조절하나요?

OTTSub에서 어긋난 자막의 싱크를 0.1초 단위로 조절하세요. 0.0s에서 시작했을 때 자막이 0.3초 늦으면 +0.3s로, 0.3초 빠르면 −0.3s로 맞춰 보세요. 주언어와 보조언어의 싱크는 서로 따로 조절할 수 있습니다.

맞춰도 시간이 지날수록 자막 싱크가 다시 어긋나는 이유는 뭔가요?

일정하게 빠르거나 늦는 자막은 고정 오프셋으로 조절할 수 있습니다. 재생할수록 오차가 커진다면 고정 오프셋 하나로 해결되지 않을 수 있습니다. Netflix가 제공하는 다른 자막 트랙도 확인하세요. OTTSub는 자막 원본의 시간표를 다시 쓰거나 영상 재생 속도를 바꾸지 않습니다.

Netflix에서 두 언어 자막을 함께 볼 수 있나요?

현재 Netflix 작품과 계정에서 두 자막 트랙을 제공한다면 가능합니다. 사이드패널에서 주언어와 보조언어를 고르고, 타이밍과 모양을 각각 조절할 수 있습니다.

OTTSub가 자막을 자동 번역하나요?

아니요. OTTSub는 Netflix가 제공하는 자막 트랙을 표시합니다. AI 번역을 생성하거나 번역 서비스를 제공하지 않으며, 작품에 없는 자막 언어를 추가하지 않습니다.

원하는 자막 언어가 왜 안 보이나요?

이용 가능한 자막은 Netflix 작품과 계정에 따라 다릅니다. 먼저 해당 작품에 Netflix가 제공하는 자막 언어를 확인하세요. OTTSub 메뉴 언어를 바꿔도 자막 트랙이 추가되거나 번역되지는 않습니다.

확장 프로그램도 Netflix도 무료인가요?

무료인 것은 OTTSub 자체입니다. 별도의 OTTSub 계정이나 구독은 필요하지 않습니다. Netflix 계정과 구독은 별도로 필요하며 OTTSub에 포함되지 않습니다.

모바일 Chrome·Safari·Netflix 앱에서도 작동하나요?

이 패키지는 데스크톱 Chrome의 Netflix 웹사이트를 대상으로 합니다. 모바일 Chrome·Safari나 Netflix 앱 내부 실행은 지원하지 않습니다. 휴대전화로 이 소개 페이지를 볼 수 있어도 확장 프로그램이 휴대전화에서 실행된다는 뜻은 아닙니다.

Microsoft Edge나 Mac은 어떤가요?

Windows의 Microsoft Edge는 로컬 호환성 검사를 통과했습니다. macOS용 Option 단축키와 일부 검증은 완료했지만 Mac 전체 검증은 남아 있습니다. 다른 Chromium 브라우저의 호환성은 확인하지 않았습니다.

일반 자막과 CC/SDH를 구분해 고를 수 있나요?

작품에서 제공한다면 일반 자막과 CC/SDH 트랙을 구분해 선택할 수 있습니다. CC/SDH에는 소리 설명이나 화자 정보가 포함될 수 있습니다. 이용 가능 여부는 Netflix에 따라 다릅니다.

자막을 AI 서비스로 보내나요?

AI 번역 서비스를 사용하지 않습니다. Netflix 서비스에서 자막 트랙을 받아 브라우저 안에서 처리하고, 환경설정은 Chrome 저장소에 보관합니다. 스토어 배포판에는 로컬 진단 기록기·분석·시청 기록 추적 도구가 포함되지 않습니다. 네트워크 요청을 전혀 하지 않는다는 뜻은 아닙니다.

Netflix의 공식 제품인가요?

아니요. OTTSub는 독립적으로 개발된 확장 프로그램이며 Netflix와 제휴하거나 승인받은 제품이 아닙니다.

개인정보처리방침

이 방침은 K2Bact가 제공하는 OTTSub Chrome 웹스토어 배포판과 이 제품 소개 웹사이트를 설명합니다. 자막은 사용자의 브라우저에서 처리합니다. 데이터 처리가 전혀 없거나 네트워크 요청을 하지 않는다는 뜻은 아닙니다.

자막 표시를 위해 사용하는 정보

OTTSub는 자막 싱크와 이중 자막을 제공하기 위해 자막 트랙의 정보·주소, 언어와 일반/CC·SDH 구분, 자막 문장과 시간, 현재 Netflix 작품 식별자와 재생 상태를 읽습니다. 별도의 시청 기록 데이터베이스를 만들거나 자막 문장을 환경설정 저장소에 보관하지 않습니다.

환경설정과 Chrome 저장소

언어·싱크·모양·학습 설정과 설정 변경 순서를 처리하는 기술 값은 Chrome 저장소에 보관합니다. 기존 구현에는 local 및 sync 저장소가 사용됩니다. Chrome 설정에 따라 환경설정 값이 Google의 Chrome 동기화 서비스로 보관될 수 있습니다. 자막 문장과 Netflix 자막 주소는 이 환경설정 기록에 포함하지 않습니다.

통신과 정보를 받는 서비스

자막 트랙은 Netflix 서비스에서 HTTPS로 받으며 브라우저와 Netflix의 통신·계정 정책이 적용됩니다. 배포판에는 개발자 운영 수집 서버, 분석 추적기, AI 번역 서비스나 자막 업로드 기능이 없습니다. 계정 비밀번호를 읽거나 Chrome 쿠키 API를 사용하지 않습니다. 선택적인 후원 링크는 사용자가 누를 때 Ctee 또는 Buy Me a Coffee를 열며 해당 서비스의 정책이 적용됩니다.

사용 목적과 제한적 사용

접근한 정보는 공개한 자막 싱크·이중 자막 기능을 위해서만 사용하며 Chrome 웹스토어 사용자 데이터 정책과 제한적 사용(Limited Use) 요건을 따릅니다. 확장 프로그램은 이 정보를 판매하거나 광고·프로파일링에 사용하지 않으며 AI 학습·번역 서비스로 보내지 않습니다.

보관과 사용자의 관리

자막·재생 작업 정보는 페이지 메모리에서 처리하고 페이지를 새로 열거나 탭을 닫을 때 해제합니다. 브라우저가 관리하는 네트워크 캐시는 OTTSub 환경설정과 별개입니다. 환경설정은 Chrome 저장소에 유지되며 브라우저의 확장 프로그램·저장소 관리 기능으로 관리하거나 제거할 수 있습니다. 일반 방문 기록 삭제만으로 확장 설정이 지워진다고 가정해서는 안 됩니다. Chrome 동기화 서비스가 관리하는 사본은 Chrome 설정과 Google 정책을 따르며 개발자가 직접 조회·삭제할 수 없습니다.

이 웹사이트

이 정적 소개 페이지에는 분석 스크립트·계정 입력 폼·외부 폰트가 없습니다. 호스팅은 GitHub Pages를 사용하며 GitHub는 로그인 여부와 관계없이 보안을 위해 방문자의 IP 주소를 기록한다고 안내합니다. Netflix·Chrome 웹스토어 등 외부 링크로 이동하면 해당 서비스의 정책이 적용됩니다. Chrome 웹스토어 링크에는 이 웹사이트·언어·링크 위치를 스토어 통계에서 구분하는 고정 캠페인 값이 포함됩니다. 개인 식별자·자막 문장·시청 기록은 이 값에 포함하지 않습니다.

문의와 변경 안내

개인정보 문의는 OTTSub Chrome 웹스토어에 표시된 개발자 연락처를 이용할 수 있습니다. 직접 문의를 보내면 사용자가 보낸 이메일 주소와 메시지가 전달될 수 있으므로 비밀번호·쿠키·접근 토큰·원본 시청 진단은 보내지 마세요. 확장 프로그램의 데이터 처리 방식이 중요하게 변경되면 안내도 갱신해야 합니다. 이 방침은 검토한 배포판을 설명하며 별도의 개발 도구에 대한 보장은 아닙니다.
