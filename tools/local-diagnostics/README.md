# 로컬 제품 진단 — .14 호버 위치 잠금 수정판

OTTSub 루트의 로컬 manifest에만 포함되는 진단 스크립트다. 별도 확장 설치 없이 기존 OTTSub와 Netflix 탭을 새로고침하면 기록을 시작한다. `version_name`에 `-local-`이 없으면 실행하지 않는 추가 방어가 있다.

현재 추가 JSON 수집 요청은 없다. 기존 자료로 .13 구현·자동 검사를 완료했다. 아래는 이후 실제 QA가 필요할 때의 사용법이다.

## 다음 시청 순서

1. 확장과 Netflix 탭을 새로고침하고 사이드패널/화면 왼쪽 위에서 `1.3.0-local-hover-lock-20261010.14`을 확인한다.
2. 사용할 주언어·보조언어와 Netflix 원본 자막 언어를 확인한다. 기존 설정이 유지되는지도 확인한다.
3. 광고 전부터 그대로 시청한다. 문제가 발생하면 왼쪽 위 **문제 표시**를 누른다(선택).
4. 본편 복귀 후 대사가 여러 번 나오도록 약 60–90초 더 시청한 다음, 전체화면을 끄고 왼쪽 위 **JSON 저장**을 누른다.
5. Chrome 다운로드 폴더의 `ottsub-local-날짜.json` 파일 경로를 알려준다. 새로고침/탭 종료 전에 저장해야 한다. JSON 저장은 기록을 중단하지 않으며, 필요하면 **기록 중단**을 누른다.

패널은 일반 창 모드에서 사용한다. 설치 직후부터 메모리에 최근 최대 12,000행을 보존하며, 한도 도달 시 오래된 1,000행씩 제거한다. 페이지 새로고침/탭 종료 시 메모리 기록은 사라진다. 자동 파일 쓰기나 서버 전송은 없으며 버튼을 눌러 로컬 파일로 저장한다.

## 기록 내용

- .13: `clockVerification`의 `session-visible-witness`는 첫 관찰과 후속 실제 대사 시작으로 세션을 확인한 경로, `session-corroborated-onsets`는 세션 진행과 두 실제 시작으로 영상 보정을 확인한 경로다. 화면·음성 싱크 성공 자체를 뜻하지 않는다. [구현·검증](../../archive/docs/repair-12-recovery-witness-2026-10-10/README.md).

- .11: 기존 clock 행의 `adMemory.ready/retained/restored`가 광고 전 관계 준비/보관/승계 복귀를 표시한다. `restored:true`는 새 경로로 검증됐다는 의미이며 화면 렌더링 성공 자체를 뜻하지 않는다. [구현·검증](../../archive/docs/repair-10-ad-clock-memory-2026-10-10/README.md).
- .10: 세션 시계에서 검증된 영상 보정 시계로 인계할 때 기존 clock 행의 selected.source/offset으로 확인한다. 새 개인정보나 권한은 추가하지 않았다. [구현·검증](../../archive/docs/repair-09-clock-handoff-2026-10-10/README.md).

- 개발판 식별자, 저장 시각, 현재 숫자 작품 ID, 사용자 문제 표시.
- 광고 판정, 차단 이유, 시계 검증 여부, video/player 시간과 후보 시간 차이.
- 원본 자막의 글자 수, 대사 전환 관측 간격, 일치 개수, 큐 개수, 검증된 시작점 개수.
- bridge 응답 상태·세션/영상 개수·채택 여부, 주기별 상태.
- .9: nativeVerification/익명 nativeTrack/선택 시계 source=session으로 원본 트랙과 본편 시계 검증 상태 기록. [구현·검증](../../archive/docs/repair-08-content-clock-2026-10-10/README.md).
- .8: gate 행의 domAd/sessionAd/sessionAdReason/sessionAdRequired로 DOM·세션·결합 판정을 구분. [구현과 검증](../../archive/docs/repair-07-session-ad-signal-2026-10-10/README.md).
- .7: 현재 작품의 세션 광고 상태·세션 원시 시간·선택 자막 언어/CC/OFF·임시 트랙 번호. [항목과 검증 경계](../../archive/docs/SESSION_OBSERVATION_2026-10-08.md).
- 주언어/보조언어/UI 언어 변경값과 저장 영역. 다른 설정/저장소 전체는 읽지 않는다.

자막 원문, 작품 제목, 영상·오디오, 계정 정보, 쿠키, URL/세션 ID 원문은 저장하지 않는다. 원본 자막은 메모리에서 일치 여부를 계산할 때만 사용한다. 로그는 관찰 자료이며 페이지 데이터의 진실성이나 실제 광고 복귀 성공을 자동으로 증명하지 않는다.

## 스토어 혼입 방지

스토어 ZIP은 사용자가 요청할 때만 생성한다. 프로젝트 루트를 통째로 압축하지 않고, 그때 `python -B scripts/package-store.py`의 허용 목록을 사용한다. 기존 ZIP은 이전 소스이며 현재 출시 승인 상태가 아니다.

패키징은 `src/`, `popup/`, `_locales/`, `icons/`, 정제된 `manifest.json`만 포함한다. 진단 스크립트 참조와 로컬 버전 표시를 제거하고, 진단 파일·참조·코드 표시가 남으면 생성 전에 실패한다. 추가 권한/background도 검토 없이 허용하지 않는다. 완성 ZIP을 다시 열어 파일 목록·CRC·내용을 검사하고 SHA256 보고서를 남긴다.

`tests/test_store_package.py`는 정상 제외와 진단 참조/코드 복사/파일·추가 권한 유입의 차단을 검사한다. 생성된 ZIP 내용 검사까지 총 5개이며 전체 로컬 QA에도 포함된다. 이러한 방어는 지정된 패키징 경로에 적용되며, 사람이 루트를 별도로 압축해 업로드하는 행위까지 막는 장치는 아니다.
